# 블로그 조종석 — 네이버 블로그 자동 글쓰기

관심 키워드나 주제를 넣으면 **AI가 글감을 찾고 → 글을 쓰고 → 사진을 구하거나 만들고 → 네이버 블로그 글쓰기 화면에 직접 입력해 발행**까지 하는, 내 컴퓨터에서만 돌아가는 앱입니다.

- **연습 모드가 기본으로 켜져 있습니다.** 실제로 올리지 않고 완성 화면 사진만 저장합니다.
- 실제로 올릴 때도 **공개 범위 기본값은 비공개**입니다.
- 로그인 정보·글·사진은 전부 이 폴더 안 `data` 폴더에만 저장됩니다.

## 준비물 (처음 한 번)

1. **Node.js** — https://nodejs.org 에서 "LTS" 버전을 받아 설치합니다.
2. **Claude Code** — 명령어를 입력하는 창에서 아래를 붙여넣고 엔터:
   ```
   npm install -g --allow-scripts=@anthropic-ai/claude-code @anthropic-ai/claude-code
   ```
   그다음 `claude` 를 입력해 한 번 로그인합니다(구독 요금제 계정).
3. 확인 — 아래를 붙여넣었을 때 숫자 두 줄이 나오면 준비 끝입니다.
   ```
   node --version && claude --version
   ```

## 앱 켜기

- **윈도우**: 이 폴더의 `start.bat` 을 더블클릭합니다.
- **맥**: 명령어 창에서 이 폴더로 이동해 `npm install` (처음 한 번) 후 `npm run dev`.

브라우저에서 **http://localhost:4123** 이 열리면 성공입니다. 명령어 창은 켜둔 채로 두세요.

## 새 버전으로 바꾸기

1. 앱이 켜진 검은 창을 닫습니다.
2. 새 버전을 내려받아 **압축 풀기**를 합니다: https://github.com/hms36903690/naver-blog/archive/refs/heads/main.zip
3. 풀린 폴더 안의 **`start`** 를 더블클릭합니다. (처음 켤 때 필요한 프로그램을 받느라 몇 분 걸립니다.)

로그인 정보·글투·사진·열쇠는 앱 폴더가 아니라 **사용자 폴더의 `naver-blog-data`** (예: `C:\Users\이름\naver-blog-data`)에 있어서,
새 폴더에서 켜도 그대로 이어집니다. 예전 버전(앱 폴더 안 `data`)을 쓰던 경우, 새 버전을 처음 켤 때 바탕화면·다운로드·문서에서
예전 앱 폴더를 찾아 자동으로 복사해 옵니다(원본은 그대로 둡니다). 열쇠 파일은 `naver-blog-data\.env.local` 에 둡니다.

## 발행에 실패했을 때 / 기록 지우기

- **최근 작업**에서 실패한 글을 누르면 **🔧 해결 방법**이 나옵니다: 무슨 일인지, 할 일, 누를 버튼(로그인·설정·다시 시도).
- **[다시 시도 (글·그림 그대로)]**: 글을 새로 쓰지 않고 발행(티스토리는 임시저장)만 다시 합니다. AI 사용량이 들지 않습니다.
- "올라갔는지 확인 못 함"이 나오면, 같은 글이 두 번 올라가지 않도록 **블로그를 먼저 확인**한 뒤 다시 시도하세요.
- **[🗑 삭제]**: 앱의 기록만 지웁니다. 블로그에 올라간 글은 그대로입니다(하루·주간 발행 수 기록은 브레이크를 위해 남깁니다).

## 쓰는 순서

1. 위쪽 **[네이버 로그인]** → 새 창에서 평소처럼 로그인. **"로그인 상태 유지"를 꼭 체크**하세요(안 하면 몇 시간 뒤 글쓰기만 막힙니다).
2. 유형(자동 발굴 / 체험단 / 브랜딩)을 고르고 내용을 넣은 뒤 **[연습으로 만들기]**.
3. 완성 화면을 확인하고 마음에 들면, 설정에서 **연습 모드**를 끄고 실제로 올립니다. 첫 글은 비공개로 올려 보세요.

## 네이버 화면 점검 (첫 실발행 전에 꼭)

[설정] → **[네이버 화면 점검]**: 네이버 글쓰기 화면을 열어 제목·본문·소제목·형광펜·사진·발행 버튼·공개 범위를 앱이 찾는지 3단계로 잽니다
(명세 6.5-b). 발행하지 않고 글자도 넣지 않습니다(시험용 작은 사진 1장만). 결과는 `naver-blog-data/debug` 에 남습니다.

## 네이버 블로그 방향(사용자 지정)

- **사업자 정보 블로그**(애드포스트 수익화 목표). 독자는 소상공인·개인사업자·법인 대표.
- 카테고리: **세금 · 자금 · 임금·노무 · 임대료 · 증여·상속 · 재무**.
- **전문성 글쓰기**: 핵심 결론 → 판단 기준(왜) → 자주 하는 실수 → 계산 예시 → 체크리스트 → 업종·매출별로 달라지는 지점. 기준 연도와 "해당 기관 확인"을 넣습니다.
- [설정] → **내 소개**에 적은 실제 경력만 글에 씁니다. AI 는 경력·상담 실적·고객 사례를 지어내지 않습니다.

- **상담 신청(인바운드)**: [설정] → 네이버 상담 신청에 네이버 폼 주소를 넣으면 모든 네이버 글 끝에 안내가 붙습니다. 자세한 설정은 `docs/INBOUND.md`.

## 티스토리 글 기준(사용자 지정)

- 본문 **1,500~2,000자**, 제목에 실제 검색 키워드, 직접 이해한 것을 설명하듯 자연스럽게.
- **AI 그림은 글마다 1~3장**(네이버·티스토리 공통, 처음 켜면 사진이 'AI가 그리기 → 일러스트'로 골라져 있음). 검색 사진을 쓰면 티스토리 2~4장.
- 카테고리: **생활정보**(검색 유입용 정보) · **금융·재테크**(자산관리·경제) · **보험·건강**(전문성·장기 독자). 카테고리마다 글의 목적과 문체가 달라집니다.
- **일주일 3편**(월~일 기준, 설정에서 변경). 이번 주 3편을 임시저장하면 더 만들지 않습니다(연습 모드는 가능). 월·수·금처럼 나눠 발행하세요.

## 제목 추천

**자동 발굴**에서 키워드(또는 건강·금융·재테크·생활경제 버튼)를 넣고 **[제목 추천 받기]**를 누르면, 요즘 뉴스·블로그를 살펴 제목 후보 8개를 보여줍니다.
마음에 드는 제목을 고르고 만들기를 누르면 그 제목으로 씁니다(안 고르면 1번). 티스토리를 고르면 내 블로그 글투와 구글 검색에 맞춘 제목이 나옵니다.

## 티스토리 (반자동 — 임시저장까지만)

이미 운영 중인(애드센스 승인) 티스토리를 지키기 위해, 티스토리에는 **발행하지 않고 임시저장까지만** 합니다.

1. [설정] → 맨 아래 **티스토리 주소**에 블로그 주소(예: myblog.tistory.com)를 넣습니다.
2. 글 만들기에서 **올릴 곳 → 티스토리**를 고르고, 위쪽 **[티스토리 로그인]**으로 카카오 계정에 로그인합니다.
3. [설정] → **[내 블로그 글투 배우기]**를 누르면 내 티스토리 최근 글을 읽고 말투·구성·분량을 배웁니다(로그인 불필요, 문장은 베끼지 않음). 배운 내용은 그 자리에서 고칠 수 있습니다.
4. 처음 한 번은 [설정] → **[티스토리 화면 점검]**을 눌러 결과를 확인합니다(아무것도 저장하지 않습니다).
5. 글을 만들면 티스토리 글쓰기 화면에 들어가 **임시저장**됩니다. 티스토리에서 임시저장 글을 불러와 읽고 고친 뒤 **직접 발행**하세요.
6. 사진은 자동으로 올리지 않습니다. 글에 노란 안내문이 들어간 자리에, 앱의 **[사진 폴더 열기]**로 연 사진을 끌어다 넣으세요.

## (선택) AI 사진 생성 — Cloudflare 열쇠

안 해도 앱은 다 돌아갑니다(사진 검색·내 사진·사진 없음).
쓰려면 `env.sample` 을 복사해 사용자 폴더의 `naver-blog-data\.env.local` 로 만들고 값을 채운 뒤 앱을 껐다 켜세요.

- 맥: `cp env.sample .env.local`
- 윈도우: `copy env.sample .env.local`

## 꼭 알아둘 것

- **자동 발행은 네이버 이용약관상 계정 제재 위험이 있습니다.** 그래서 연습 모드가 기본값이고, 하루 발행 수(기본 3편)·발행 간격(기본 30분)·전체 중단 장치가 있습니다. 이 숫자는 네이버가 정한 값이 아니라 이 앱의 자체 브레이크입니다.
- **검색으로 가져온 사진은 저작권 분쟁 소지가 있습니다.** 워터마크·사람 얼굴 필터가 있어도 라이선스를 보장하지 않습니다. AI 생성이 더 안전합니다.
- 국내 인물 사진은 초상권 위험이 있어 애매하면 빼는 쪽으로 판정합니다.
- 브랜딩 글은 사용자가 준 숫자·실적만 씁니다. 수집 자료는 참고용이며 그대로 베끼지 않도록 지시합니다.
- 윈도우 동작(폴더 선택창, claude 실행)은 아직 실제 윈도우에서 확인하지 못했습니다.

## 개발자용

- 원본 명세(프롬프트)는 공개 저장소에 두지 않고 따로 보관합니다 · 만들면서 새로 알아낸 함정: `docs/FINDINGS.md`

- `npm test` — 계산·안전장치·수집 필터·최소 재현(계정·AI 불필요)
- `npm run test:harness` — 가짜 에디터(scripts/harness)로 입력 순서 검증
- `npm run test:ai` — 실제 claude 호출 검증(구독 사용량 소모)
- `npm run test:tistory` — 가짜 티스토리 화면(scripts/harness/tistory.html)으로 반자동 저장 검증(발행 버튼 0회 포함)
- 네이버 셀렉터는 전부 `lib/scrape/selectors.ts` 한 파일에 있습니다. 바뀌면 후보 배열 **앞에 추가**하고 기존 값은 남기세요.
- 에디터 자동화의 각 함정은 `lib/naver/publish.ts` 의 ⚠️ 주석에 이유와 함께 적혀 있습니다.
