# 네이버 블로그 인바운드(상담 신청) 설정

흐름: 네이버 검색 → 사업자 정보 글 → 글 끝 "무료 상담 신청" → **네이버 폼** 신청서 → 응답이 표로 쌓임(= DB)

## 1. 네이버 폼 만들기 (form.naver.com)

**항목(추천)**
1. 성함(또는 상호) — 단답형, 필수
2. 연락처 — 단답형, 필수
3. 업종 — 단답형
4. 상담 분야 — 객관식(여러 개 선택): 세금(부가세·종소세) / 임금·4대보험 / 임대료·상가임대차 / 정책자금 / 증여·상속 / 기타
5. 궁금한 내용 — 장문형
6. 연락 가능한 시간 — 단답형
7. **개인정보 수집·이용 동의** — 객관식(동의함 / 동의하지 않음), 필수

**개인정보 수집·이용 동의 문구(예시 — 상황에 맞게 고쳐 쓰세요)**

> 상담 신청을 위해 아래와 같이 개인정보를 수집·이용합니다.
> - 수집 항목: 성함(상호), 연락처, 업종, 상담 내용
> - 이용 목적: 상담 신청 확인 및 연락
> - 보유 기간: 상담 종료 후 1년 (요청 시 즉시 삭제)
> - 동의를 거부할 수 있으며, 거부 시 상담 신청이 제한됩니다.

## 2. 앱에 신청서 주소 넣기

앱 [설정] → **네이버 상담 신청 (인바운드)** → 신청서 주소에 네이버 폼 **응답 주소**를 붙여넣기.
그 뒤 만드는 모든 네이버 글 끝에 [구분선 → 안내 문구 → 신청서 주소]가 붙습니다(티스토리에는 붙지 않음).

## 꼭 지킬 것

- **세무사법**: 세무 신고 대리·세무 상담료는 세무사만 할 수 있다. 안내 문구는 "정보 정리 + 세무사·노무사 연결" 형태로.
- **개인정보**: 동의 없이 연락처를 받지 않는다. 응답 표는 비밀번호가 걸린 계정에서만 본다.
- **네이버 상업성**: 글당 안내 1개, 짧고 담백하게. 본문 곳곳에 광고 문구를 넣지 않는다(앱이 AI 에게 금지해 둠).
